## 1. 验证层次与结果表达

| 层次 | 验证内容 | 不能替代的结论 |
| --- | --- | --- |
| 规则与模型测试 | 解析、类型、提取、分组、顺序、冲突、修订和状态机 | 不证明网络真的转发到正确目标 |
| 本地协议集成 | 真实代理进程内链路、受控 HTTP/HTTPS 服务、流式与大文件 | 不证明公司业务身份或客户端兼容 |
| 生产 UI 验证 | 真实 View/Model 交互、虚拟列表、详情、编辑器、诊断 | 不证明真实 Host 的 Dock、依赖加载和系统设置 |
| 真实 Host/客户端 | 加载、作用域、窗口、关闭退出、目标客户端接入、代理恢复 | 不代表所有客户端/协议均已支持 |
| 性能与交付 | 指定设备上的负载、资源曲线、包内容、干净安装 | 不代表正式发布已发生 |

每阶段采用必要的最小验证组合，并持续回归前置行为。只有文档变化时检查内容、链接、空白和状态一致性，无需运行与修改无关的业务测试。

V4 专项把紧凑度、用户/程序滚动区分、视口锚点、独立跟随、正文模式、筛选/快照范围、方向导出、焦点及平台迟到列为可验证契约。后续 UX 开发门禁须在同一轮完整校验 50 项 M0、53 项 V3 和 40 项 V4，保留原资源阈值与人工边界；本轮不使用 AIFLOW、Windows CI、Release 或发布门禁。

## 2. 受控样本与测量负载

自动场景使用本地可控端点、合成身份和确定性输入。CGate 地址用于产品举例；真实服务与账号验证另行记录。受控目标 A/B 返回可区分标识，并记录收到的方法、路径、头、正文和时间，防止只检查客户端 URL 就误判映射成功。

| 样本集 | 建议内容 | 使用阶段 |
| --- | --- | --- |
| 普通接口 | GET/POST、JSON/表单、多值 Query/Header、Cookie、编码、失败/延迟/取消 | M0 起 |
| 流式内容 | SSE 跨块 UTF-8 与分隔符、逐行 JSON、心跳、断开、持续输出 | M0 起 |
| 大资源 | 128 MiB 与 1 GiB 生成式二进制、未知长度、分段响应、损坏或高像素图片 | M0/M1 起 |
| 业务分组 | 多来源同字段、不同字段组合、缺失/未知、凭据变化、并发与相同开始时间 | M2 起 |
| 规则链 | 匹配/不匹配、优先级冲突、改写循环候选、在途切修订、解析超预算 | M2/M3 起 |
| 交互负载 | 10,000 条元信息、20 个并发请求、5 条持续流；持续流先测 10 分钟 | M1 起 |
| 稳定性 | 至少 1 小时混合捕获、20 轮页面开关及起停；M6 根据实测扩大 | M6，前置阶段先小规模运行 |

以上数字是初始验证负载建议，不是已测容量或产品性能承诺。M0 记录设备、运行环境和基线，M1/M2 设定预算后固定负载与通过阈值；改变条件应产生新记录。持续流/大文件用生成器产生，不把大二进制提交到仓库。

需要测量：代理开关前后的延迟/吞吐、活动流数量、内存与队列峰值、磁盘记录量、首次内容可见时间、UI 响应/刷新、规则执行耗时、关闭收口时间和释放后残留。记录过程峰值与随时间变化，不能只报告结束时的值。

## 3. 业务验证矩阵

| ID | 阶段 | 场景 | 通过条件 |
| --- | --- | --- | --- |
| T00 | M0 | HTTP/HTTPS 基本转发与证书状态 | 客户端取得真实端点响应，失败状态明确；停止后监听释放 |
| T01 | M0 | HTTP/2 实际链路与目标切换 | 记录两侧协议和端点结果；支持范围与限制有证据，不从库文档直接推定 |
| T02 | M0/M1 | SSE 跨块、增量与中途取消 | 首条事件在响应结束前可见；事件/字符不损坏；取消后有界结束 |
| T03 | M0/M1 | 大文件与未知长度 | 转发正确，内存受预算限制；已接收字节真实，未知总长不伪造百分比 |
| T04 | M1 | 图片预览与损坏输入 | 解码受尺寸/像素/并发预算限制，失败不阻塞捕获 |
| T05 | M1 | 仅元信息/部分/完整记录、配额和写入失败 | 记录完整性准确；超限按策略处理；搜索和导出说明实际范围 |
| T06 | M1 | 保存、重开、异常中断 | 元信息及内容索引一致；未完成响应不伪装完整；重开不自动重发 |
| T07 | M1 | 多页面、暂停跟随与关闭 | 单监听器共享，视图独立；暂停显示继续接收；关闭释放订阅 |
| T08 | M2 | 四位置提取、组合键、多值及类型转换 | 符合 DSL 明确语义，可追查来源；不内置 at；错误状态与缺失分开 |
| T09 | M2 | 语法错、循环依赖、慢表达式/解析超限 | 诊断可定位，预算和取消生效；旧有效规则继续可用 |
| T10 | M2 | 时间窗口、并发、同刻顺序与进行中请求 | 窗口计数确定；开始顺序稳定；并发重叠和长流清晰 |
| T11 | M2 | 标识变化、未知身份、来源过滤与重新分组 | 组数不冒充人数；人工流量可排除；修订和覆盖范围可见 |
| T12 | M3 | 全域名与字段定向映射 | A/B 端点证明实际目标，未命中请求保持预期目标；路径和输入正确 |
| T13 | M3 | HTTPS Host/authority/SNI、Cookie/Origin 等差异 | 目标身份与声明策略一致，业务环境差异单列；不通过忽略证书验证掩盖错误 |
| T14 | M3 | 路径/参数/头/JSON 修改及冲突 | 有效快照与端点收到内容一致；长度/编码正确；冲突和动作顺序明确 |
| T15 | M3 | 在途修订、失败策略、循环与流式回传 | 每请求使用固定修订；不循环、不静默退回原环境；原始记录保留 |
| T16 | M4 | 手工 GET/POST、变量和模板 | 预览与实际发送一致，未解析变量不发送；模板保存后可用 |
| T17 | M4 | 原始/有效快照重发与规则应用选择 | 恰好一次用户执行，规则不意外重复；新旧记录关联且原记录不变 |
| T18 | M4 | 部分请求体、发送取消/超时、自代理回流 | 缺内容不误当完整；不自动重试非幂等请求；无循环或重复统计 |
| T19 | M4 | 重发的流式/大响应与差异查看 | 沿用 BODY 预算，输出增量可见；无法完整比较时明确范围 |
| T20 | M5 | 结构化文档、网页地址、纯手工说明 | 支持范围与不支持项明确；三种来源均能关联；缺文档不阻塞抓包 |
| T21 | M5 | 文档刷新、失败、手工修订与版本 | 不覆盖手工内容、不修改生效规则或用例；来源/时间/版本可查 |
| T22 | M6 | 配额、慢磁盘、长时负载与取消 | 固定预算内运行或按策略降级，缺口可见；无持续无界积压 |
| T23 | M6 | 真实 Host 加载、Dock、两主题与多页面 | 正式插件加载和生产操作有效；Standalone 结果不冒充 Host 结果 |
| T24 | M6 | 停止、正常退出、启动恢复与设置所有权 | 监听/任务释放，代理设置按实际所有权恢复；外部已修改的配置不被盲目覆盖 |
| T25 | M6 | 包内容与干净安装 | 私有依赖齐全、共享依赖边界正确、无 Standalone/Tests 混入；结果独立于正式发布 |

T01/T13 等协议项在 M0 先验证最小链路，在 M3 用真实规则执行链重新验证。所有阶段都回归相应的停止、资源、原始记录和来源语义，不能用探针通过替代产品功能通过。

M0 的 T00～T03、T12/T13 改写前置及 T07/T24 所有权前置，按 [V2 专用矩阵](network-traffic-v2-m0-verification-plan.md)第 12 节细化；它不改变 M1/M3/M6 的完成状态。V2 仅执行本地开发门禁，不使用 AIFLOW、Windows CI 或发布门禁。HTTP/2 调查必须执行，明确不支持/回退可成为范围结论，不能记作完整 h2 兼容。

## 4. 人工演示清单

- H01：真实客户端接入，HTTPS 状态可理解，普通请求及持续响应可查看。
- H02：编写字段规则并修改提取位置，保存两种视图；解释组数和并行顺序。
- H03：启用映射前预览目标，启用后观察原始/实际请求与命中记录，再关闭规则复核。
- H04：从组内选一条请求，修改环境和输入重发，对比结果，确认真实行为视图未重复计数。
- H05：查看图片与文件，辨认预览截断和实际记录缺失，导出已保存内容。
- H06：文档链接与手工说明关联、刷新和修订保护；无文档场景仍能使用。
- H07：真实 Host 中多页面、Tool、布局、退出和再次启动，确认运行状态与设置恢复符合约定。

人工结果逐项记录通过、失败或未执行。某次目标客户端通过只代表该客户端及其当时配置。
