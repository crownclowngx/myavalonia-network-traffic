# V8 · M5 文档辅助专用验证矩阵

> 编写日期：2026-10-03。状态：**验证方案，业务实现/测试/map/profile/M5 门禁均待落地；下列数量不是已通过结果**。
> 配套：[V8-01～18 执行计划](../roadmap/network-traffic-v8-m5-documentation-plan.md)、[专项设计](../design/network-traffic-v8-m5-documentation-design.md)。
> SOLID 为首要规定，朴素设计，关键实现、测试与脚本采用详细中文注释并解释原因。仅本地 Debug 开发验证，不使用 AIFLOW、Windows CI 或发布门禁；正式发布时再启用对应门禁。

## 1. 分层、场景数与证明边界

| 层次 | 主要对象 | 证明方式 |
| --- | --- | --- |
| 单元测试 | 来源状态、纯 Reader/引用、身份/匹配、手工覆盖、差异、草稿建议、预算、代次 | xUnit、合成夹具、可控时钟和任务完成顺序；不访问真实业务网络 |
| 协议测试 | 真实 HTTP/HTTPS 获取、编码、限额、取消、认证/重定向、自代理拒绝 | 本地受控服务记录收到的方法、目标、请求次数、传输字节、取消及连接事实 |
| 文件/组合测试 | 生产文件库、CAS、原子替换、配额、迁移、恢复、组合根与寿命 | 隔离临时目录、故障注入、双页生产服务；Fake 不能代替真实文件故障证明 |
| 生产 UI 自动验证 | 实际来源操作、预览/差异、手工编辑、匹配面板、M4 草稿入口 | 生产 View/命令 + Fake 外部边界，Headless/Skia；单列物理输入和真实 Host |
| 资源测量 | 大输入、引用展开、索引、长时混合、挂卸、停止 | 原始采样+profile重算、真实任务与租约计数；不只写 bounded=true |
| 工程审阅 J | SOLID、中文注释、朴素设计、依赖、文档和范围 | 实际代码/差异/取舍路径；不计入业务 TRX 数量 |
| 门禁自测 G | 漏映射、错误结果、坏/旧证据、能力缺口和入口绕过 | 检查器正例→逐项破坏→真实入口拒绝→恢复正例；独立临时目录 |
| 人工验收 H | 真实来源、Standalone、Host、鼠标键盘、最终流程 | 带时间/环境/步骤的真实记录，不由自动场景推定 |

本矩阵固定 **72 项业务自动场景 = A8 + P8 + M8 + E8 + T8 + S8 + U8 + R8 + C8**。完整累计要求 **431 项 = 207（M0/M1/UX/M2）+ 72（M3）+ 80（M4）+ 72（M5）**。一个场景可需多个测试方法和参数行，一个方法也可证明多个场景，但每条断言必须有真实映射；不以场景数虚报测试方法数。

所有自动数据合成，来源域名使用 example.test 系列或受控回环地址；不读取用户文档库、公司文档、真实令牌或浏览器会话。默认自动过程不打开真实浏览器，不改系统代理/证书信任，不发送业务写入。协议测试证书只在测试进程信任。

统一边界：每个数字预算覆盖低于、等于、超过；并发明确控制 A 晚于 B、取消后完成、UI 排队后关闭和提交竞争。时间测试优先可控时钟，真实网络/性能测量另行采样，不靠不稳定 sleep 碰概率。

## 2. 来源获取与状态（A）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| V8-A01 | 合法 HTTP/HTTPS、带普通 Query、非法 URI/scheme/userinfo/CRLF/fragment、自代理 IP/别名 | 合法目标一次 GET；非法或自代理目标零发送；实际连接目标、Host/TLS 身份与校验结果一致 |
| V8-A02 | 临时 Authorization/令牌 Header、敏感 Query、缺值、变更认证上下文、协议控制头 | 凭据只送指定来源；缺值/非法头零发送；不使用默认认证/Cookie；日志/持久化/异常不含合成敏感哨兵 |
| V8-A03 | 301/302/307、401/403/404/429/500、DNS/TLS/连接失败 | 无自动跳转/重试/认证重发；次数准确、错误可区分；Location/Retry-After只作提示，不触发新任务 |
| V8-A04 | identity/gzip、未知编码、无/错误 Content-Type、200 HTML登录页、坏UTF-8、截断、压缩膨胀 | 原始和解压字节分别限额；不支持与坏文档有诊断；前缀不当完整快照；无无界缓冲 |
| V8-A05 | 初次、显式刷新、相同摘要、ETag/Last-Modified、合法/无旧快照304 | 第一次需要明确应用；304不新建内容修订；检查时间与快照时间分开；身份/地址变化不复用错误 validator |
| V8-A06 | 10秒头/30秒总期限、读取中取消、解析中取消、超时后的迟到响应 | 取消/失败不替换旧文档；真实任务/流≤1秒收口；无隐藏继续下载/保存；不能只取消等待方 |
| V8-A07 | 连点获取、两页同源、不同来源、删除/改地址后旧响应到达、旧finally | 容器并发≤2、页面单意图；只有当前代次可提交；旧任务不清新Busy，不复活删除来源 |
| V8-A08 | 获取成功预览未提交、取消预览、120秒过期、另一页提交后应用 | 获取/解析本身零库变更；提交校验SourceRevision/LibraryRevision/代次；失效预览要求重建，不静默覆盖 |

A01～A06 必须有真实受控协议测试，单元 Fake 仅证明状态用例。内网/回环允许值与自代理拒绝必须同时覆盖，不能为了拒绝测试把全部内网文档禁掉。

## 3. 结构化解析与支持范围（P）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| V8-P01 | 3.0.3 JSON正常/空paths；YAML、Swagger2、其他版本、缺根必需字段、重复属性 | 支持/空成功/不支持/损坏分别表达；整体失败保留原已应用修订，版本不能猜测降级 |
| V8-P02 | 方法/路径/summary/tags/deprecated；TRACE、缺operationId、重复operationId、坏路径 | 核心身份用SourceId+方法+路径；TRACE可读而不可自动构造；局部错误定位且能力标记真实 |
| V8-P03 | 路径层/操作层参数覆盖、同层重复、四位置、缺必需path定义、style/explode | 合并与大小写规则正确；不支持序列化不冒充标量；缺参数定义禁用受影响构造 |
| V8-P04 | 本地ref到schema/parameter/requestBody/response/example、安全定义，~0/~1与片段转义 | 目标存在且类型匹配；缓存复用；错类型/缺目标/$ref额外字段按固定契约诊断，不混合出伪字段 |
| V8-P05 | 自引用、互引用、深链、共享子树指数展开、相对/HTTP/file外部ref、externalValue | 循环有限展示；总访问/深度有界；所有外部引用零网络/零文件读取，未展开分支明确显示 |
| V8-P06 | 基本类型/required/enum/null/default、超大数字、allOf/oneOf/anyOf/not/discriminator | 0/false/空/null不同；数值精度保留；不隐式选择组合分支或声称完整schema验证 |
| V8-P07 | 多request媒体类型、多个示例、responses/default/headers、multipart/XML/binary | 可读与可填分开；响应示例不成真实响应或Mock；不支持正文不被改成空发送 |
| V8-P08 | servers层级/变量/相对地址/缺server、根/操作security覆盖、扩展字段与HTML说明 | 只提供待确认目标；不自动认证/访问链接/加载图片；未知扩展可忽略但已知字段错误不可吞掉 |

夹具拟放 `docs/examples/m5/`，含受支持、局部不支持和致命错误三类，配预期诊断/投影。生产 Reader 必须实际读取这些文件；测试自建另一份等价输入不能代替文档样例可执行验证。首版不新增 YAML 库，若后续变更格式范围须同步计划/锁文件/测试与实际依赖理由。

## 5. 更新差异与手工保护（E）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| V8-E01 | 新增/修改/删除接口、字段、示例和说明，应用/放弃差异 | 未应用前库不变；应用后导入层完整切换，来源/修订可查；取消不半更新 |
| V8-E02 | Inherit/Set/Hide、Set空字符串、手工新增字段、恢复来源值 | 三态不同；刷新保留Set/Hide；空值不回退，恢复来源只清对应补丁 |

| V8-E07 | 双页同时导入/手改/改绑定、提交前取消、提交成功后取消 | CAS冲突无丢写；先提交保留；提交后取消报告已应用，旧UI不污染新页 |
| V8-E08 | 删除来源并保留手工/删除全部/取消、仍有模板引用、迁移写失败 | 删除目标和后果清楚；保留转换原子执行；模板引用失效可读，无自动重建/下载 |

## 6. 请求草稿辅助（T）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| V8-T01 | 选择绑定/环境、server候选、baseUrl、缺目标或未解析变量 | 不自动采用首server/文档域名；建议经M4变量/目标校验，缺项零发送 |
| V8-T02 | path标量、query标量/重复数组、header、中文/+/百分号/斜杠/CRLF | 支持序列化编码一次、有序多值保留；M4校验协议头；注入/不支持style不偷换实现 |
| V8-T03 | 缺必填、required空/null/0/false、enum、optional无值、复杂cookie/schema | 不编造值；不可完整构造有明细；转部分草稿为明确选择并保留待补提示 |
| V8-T04 | 单/多JSON示例、readOnly提示、文本、平面form、无示例、超预算 | 明确选择示例；不递归造正文；类型和原始数值保留；超限/复杂正文不默认为None |
| V8-T05 | Authorization/Cookie示例、apiKey、安全方案备选/组合、OAuth、RawFile/multipart | 凭据只建敏感占位，不用示例认证；不登录/读文件/自动上传；不支持能力明确提示 |
| V8-T06 | 建议预览/采用/取消、当前脏草稿、旧PreparedRequest、重复点击 | Builder零I/O；用户未采用草稿不变；采用走Load并失效旧预览；保留/放弃/取消语义正确 |
| V8-T07 | DocumentOrigin、无CaptureOrigin、ApplyRules默认false、显式M4发送与模板保存 | 实际来源Manual且身份可追查；只由M4用户发送；创建建议/查看说明零发送零模板写入 |
| V8-T08 | 生成后文档/绑定/环境说明变化、来源删除、从新版创建草稿 | 原草稿/模板/Attempt字节不变；新版只影响新意图；旧来源失效不自动补网或重建请求 |

T07 必须数真实业务端点收到的请求，文档GET次数与业务发送次数分开；仅观察“Send按钮没被点击”不够。文档转草稿产生的新预览继续沿用M4一次接纳/取消/未知结果语义，不复制发送协调器。

## 9. 资源、并发与寿命（R）

| ID | 场景 | 必须断言 |
