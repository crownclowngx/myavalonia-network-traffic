## 3. 验证方式与已发现问题

`UXWorkspaceTests` 使用生产记录器、日志与归档，注入假时钟和可控任务验证 200 ms 消抖、组合文字草稿、迟到查询、选择/范围、正文模式、反馈水位、选择器及双方向导出。万条摘要测试保留重复 URL 和活动记录，不直接伪造 ObservableCollection。

`UXCaptureUiTests` 使用生产 View、真实绑定和 Headless 鼠标/键盘；按实际 Bounds 测密度。前轮 20 张图已逐图复核，完整轮仍重新生成和检查。前轮局部实测为 800×600 顶部 76 DIP、行高 48 DIP、9 条完整行，520×420 正文视口 202 DIP；最终数值从完成轮布局 JSON 读取。宽窄往返、分隔条拖动、查找选区、逐层关闭及 20 轮重新附着有独立断言。

`UiProbe` 继续发送一万真实请求，达到 20 路混合负载，保留 5 流持续至少 600 秒，开关页面 20 轮。V4 新增真实插入和每轮修订的同身份锚点观测，并核对退出后句柄。句柄基线在 20 路连接及首个正文控件预热后取得；私有内存沿用 M1 既有基线和阈值。采样是 Dispatcher 操作/布局时延，不是物理键鼠时延。

本地门禁自测累计 328 个拒绝检查，包含原 M0/M1 205 项。V4 自测从完整正例开始，对映射、身份、图片、几何、读取/保存、资源和继承证据逐项破坏，再恢复正例；夹具只写 GateSelfTests。

首次普通测试有一项 TLS 错误证书拒绝场景在连接收口时超时；定向复测通过。未修改证书验证/连接截止或放宽门槛。第一轮完整 UX 在普通测试发现操作错误被通用故障覆盖，已保留具体阶段说明；并补测扩大筛选后计数归零、真实浏览按钮取消焦点及遮罩/原值复制。修复后重新开始整轮，不沿用失败轮的结果。第二轮普通测试 169/169 通过后，检查器中一处手写预期摘要被发现有笔误；主动终止该轮，仅结束本轮进程树。预期值改为由固定合成文本 `first` 计算 SHA-256，实际业务字节及其断言未改变。短桌面探针可运行后重新开始第三轮完整检查；短测不替代 600 秒持续测量。第三轮普通测试再次通过后，焦点自审发现工具栏到工作台的局部快捷键路由缺失；主动中止资源段，补齐冒泡路由，并用实际键盘验证工具栏 Ctrl+L/F 和连续 Esc。不注册 Host 全局快捷键，子控件已消费的键不会重复执行。

## 4. 实现取舍与仍需实际环境验证的部分

- 保存弹层使用“浏览父目录 + 可编辑最终完整新路径”，合并子目录名编辑，最终路径仍通过原归档服务检查；没有额外路径管理框架。
- 五个详情标签在支持的最小 520 DIP Document 中单行排列；文件次级入口放打开菜单，未增加通用标签溢出框架。分栏与正文模式只在当前 Document 寿命内记忆。
- 树形查找会切至文本；图片和事件视图会提示查找范围，正文查找不扫描磁盘或隐藏字段。普通文本/JSON 查找最多 256 字符。
- 自动检查原生选择器通过公开平台适配和可控返回验证，不能证明真实宿主的对话框外观、系统剪贴板或 DPI。平台不可用时可手工输入路径。
- 单元/受控流/UI/Desktop 分层共同覆盖矩阵，不把纯状态测试说成物理输入；10,000 行虚拟化与持续负载仍由 Desktop 生产视图证明。
