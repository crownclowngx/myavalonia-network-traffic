公开 API 核对及真实 h2 探针发现：固定版 TerminateSession 的 CancellationTokenSource 属于连接，native h2 流处理中可能已释放；私有流取消入口不能作为生产契约。实现因此采用**HTTP/2 空闲仅提示**：不自动取消、不错误标终态、不终止同连接其他流；客户端可取消目标流，Stop 终止整次运行。接入面板、记录概览、P06 和门禁均同步该范围。没有维护 fork、反射私有成员或伪造自动取消支持。

## 4. 调查修复与首版取舍

开发中修复：未知长度上传不能在响应头到达时提前 Complete；记录正文提交前需要 flush 让快照可读；快照补头必须冻结日志位置以避免后续淘汰；复制取消在 commit 故障边界后再次检查；存档先校验实际长度再哈希；错误 Body/重复身份/伪完整状态拒绝；路径检查覆盖父级重解析点；列表换不可变摘要不能误选同索引另一请求；中文预览按 UTF-8 字节截断后必须保留截断标记。

后续交叉校验发现未知长度取消的上游可能产生部分正文回执。取消测试移至 Stop 前读取真实终态后，成功复现错误 Complete；固定依赖在 chunked 块边界遇到 EOF 会补写上游结束块。现由捕获会话单独记录公开 IsLastChunk 所证明的客户端原始结束块，缺失时请求方向为 Partial/IncompleteFraming，不把成功响应当作原上传完整。门禁比较完整生成体、观察前缀与实际回执的摘要，并拒绝 Stop 前伪 Complete；新增对应反例。

测试夹具使用生成式 64 KiB 缓冲，Kestrel 测试上游显式解除默认上传大小限制；真实上传和下载均核对内容摘要。Headless 以有效 PNG 实际解码，窄屏详情布局调整了标签间距/字号与滚动范围。协议限制不是通过放宽资源门槛解决，M0 阈值保持。

首版范围取舍详见[设计第 13 节](../design/network-traffic-v3-m1-capture-design.md#13-首版实际落点与设计取舍)：压缩流只尝试有限前缀预览；事件环不持久化，历史只从正文重建；存档/导出必须在捕获根之外；元信息只读加载有 32 MiB 上限；历史会话管理页及偏好持久化留后续。保留完整性、配额和停止要求。
