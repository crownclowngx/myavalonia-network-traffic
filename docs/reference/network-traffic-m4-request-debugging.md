# M4 请求调试当前实现

> 2026-10-03：V7 独立、无规则请求调试已接入生产界面。**完整 M4 未完成**。目标契约仍以 [V7设计](../design/network-traffic-v7-m4-request-debugging-design.md)为准，实际证据与差距见 [实施记录](../archive/2026-10-03-v7-m4-implementation.md)。

## 入口与职责

HTTP 工作台的“打开”菜单提供“请求调试”和“从选中记录提取请求”入口；返回抓包仍在同一菜单。草稿按 Document 独立；主动执行、正文资产、模板/环境库和历史按插件容器共享。请求调试无需启动代理，也不替换真实抓包的当前会话。

`Application/Requests` 负责离线准备、变量、快照判定、执行协调和比较；`Infrastructure/Requests` 负责 HTTP、文件和记录器适配；`Features/Requests` 负责编辑、命令与异步结果代次。复用 CaptureWorkspace 查看结果、SSE/NDJSON、图片及保存存档。没有通用工作流、通用仓储或动态格式插件层。

## 编辑与预览

| 项目 | 当前约定 |
| --- | --- |
| 方法 | UI提供GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS；核心接受合法token，拒绝CONNECT/TRACE；GET/HEAD需None |
| 地址 | HTTP/HTTPS绝对地址，最长8192字符；不接受userinfo、fragment、空白、反斜线、坏百分号 |
| Query | 最多256项；编辑区每行保留原始编码、空参数段与重复键；自动与URL同步；`# `行首禁用该行；模板恢复禁用行 |
| Header | 每行`Name: Value`，可重复；`# `禁用；最多256行、UTF-8计费64KiB；拒绝CR/LF及非法字段 |
| 正文 | None、UTF-8 Text、严格JSON、urlencoded Form、单个RawFile；Form每行`name=value`，`# `禁用 |
| 文件 | 选择时复制为完整不可变资产，最多64MiB；后续修改原文件不会影响已冻结发送；不做变量替换 |
| 派生字段 | Host、Content-Length、Connection、Content-Type等由发送器管理；不允许手工注入framing、Expect、代理认证或旧实体摘要 |
| 预览 | 显示最终方法、URI、环境修订、派生头、已解析普通头、有限正文及非敏感摘要；完全离线 |
| 失效 | 编辑、环境变化、重新加载修订、关闭或120秒到期使预览失效；每个token只能消费一次 |

文本/JSON/Form编码后最多256KiB。JSON最大深度32、token16384，拒绝重复属性、BOM、注释和尾逗号；数字不经过浮点转换。JSON会按编辑语义序列化，Form会重新编码，不承诺复原原始TCP字节、空白或头大小写。需要保持完整原始实体字节时使用RawFile。

Form字段的首尾空格属于值本身，按`+`编码，不沿用Header排版空白的裁剪规则。“清除环境选择”只清除当前页选择并使旧预览失效，不删除保存的环境。

普通签名头不会自动重签；改变地址或正文后需自行更新业务签名。当前界面使用朴素的逐行编辑器，还没有独立参数表格、完整自定义方法输入控件或所有细粒度错误定位。

## 变量、凭据和模板

变量使用`${name}`；`$${`表示字面`${`。优先级为模板默认值、环境值、本次值。名称区分大小写，同作用域重复拒绝，单作用域最多64项、每值4096字符。只扫描一次，替换结果不递归求值。

`${baseUrl}`仅允许出现在地址开头，值为HTTP/HTTPS origin；普通变量不能改变协议、主机或端口。路径/Query变量进行一次组件编码；JSON只在字符串值中插值；Form逐字段编码。

本次变量以`!name=value`标记敏感值，输入默认遮蔽，可在当前页面显式显示。Authorization/Cookie自动敏感；敏感标记不能被普通覆盖值降级。敏感预览隐藏路径、Query、头值和正文摘要；请求记录不保存敏感正文，自动历史不保存Query。不会自动登录、携带系统凭据、管理CookieJar或执行脚本。

模板保存未解析输入，自动移除运行期敏感变量，将具体身份头改为待填写占位符。普通环境可保存；含敏感变量的环境拒绝提交。无法自动识别所有私密字面量，正文/地址等位置需要使用明确标记的变量。服务器响应和用户主动选择的文件仍可能包含私密原文，内容记录不提供通用脱敏。

模板、环境支持另存、载入、更新和删除。提交基于整库修订比较，另一页已更新则拒绝覆盖并要求重新加载。`requests.json`使用schema1、最多8MiB、200模板和50环境；坏文件和未来版本保留原样。文件模板先校验并固定资产，再原子替换索引；失败回滚新资产固定状态。删除模板后，在途租约归还才回收文件；回收失败保留计费资产，在后续提交时重试。

schema1草稿可选字段`QueryEditorText`保存含禁用行的编辑原文；缺省时从地址恢复。库校验及预览要求其有效行与地址中的Query完全一致，避免出现两份不同的发送事实。模板不能携带运行期`Origin`；正常保存会清除来源，外部伪造来源的库提交会被拒绝。

## 来源、执行和结果

当前旧schema1只有一份头/正文。仅在元信息完整、OriginalUri等于EffectiveUri、请求正文完整且编码为identity实体时，允许提取`LegacyObserved`草稿。提取与比较固定同一记录修订，过滤hop-by-hop及其Connection提名字段，身份值转为必填变量。完整二进制或超过文本上限的正文在64MiB内流式转为RawFile。未知空正文、前缀、损坏文件和不可靠映射均拒绝，不能按空请求发送。

**原始/当时有效双快照和“应用当前规则”不可用。** 选择规则的核心调用返回RQ007，界面明确显示M3尚未接通。M4不升级Titanium，不通过反射或fork绕过V6能力缺口。

一次显式发送创建一个Attempt。最多4项执行，超额立即拒绝；无隐式后台队列。每次新建HTTP/1.1连接，禁止系统代理、重定向、CookieJar、自动凭据与解压；同一Attempt只允许一次连接回调。DNS候选中含本插件回环代理端点则拒绝，使用同一次解析的首个候选连接，连接后再核对监听端口；TLS名称保持最终URI主机。失败不自动换地址或重发。

调度事实为NotSent、DispatchStarted或ResponseHeadersReceived，执行终态为Completed、Cancelled、TimedOut、Failed等。连接/收头30秒、正文空闲60秒、总寿命30分钟；SSE字节更新空闲活动。取消实际结束读取、响应、客户端和正文租约。已派发后取消/失败显示“远端结果可能未知”；收到头后失败保留HTTP状态。HTTP 4xx/5xx仍可表示传输完成，与业务成功、正文保存完整分开。

主动记录使用Manual/Replay及OriginRecordId，调试会话独立；DSL来源映射为manual/replay，默认分析仍选择capture。`history.json`只保存脱敏执行摘要，最多1000项和8MiB；接受意图先落盘，再开始派发。重启时未结束项标为Interrupted，保留已知HTTP状态，不恢复发送。正常退出清理调试缓存，尚被只读租约持有时延期至下次持根锁启动；显式存档和模板资产不在清理根内。

## 对比和预算

比较方法、目标、状态、总耗时、请求/响应头和双向正文。每侧每方向读取至多256KiB；文本按位置逐行，JSON对象按属性、数组按下标，二进制仅在完整性可证时比较完整实体摘要。敏感头、缺元信息、部分正文、不同编码/未知表示、坏JSON都不能给出“全文相同”。压缩实体不在此处解压。

比较最多两项、两秒、4000行、500差异、100000操作，单结果字段最多1024字符；页面切换或迟到结果不覆盖新选择。准备与比较复用32MiB内容额度。文件资产单个64MiB、合计256MiB；代理、调试记录和资产通过ManagedDiskBudget共用4GiB上限，其中33MiB为索引、原子提交临时副本和资产元信息固定预留。已删会话的预留在当前容器中保守计费，下次启动重新扫描，可能提前拒绝继续保存，但不会扩张额度。

容器级16MiB草稿与库投影总额控制尚未实现；现有逐字段、库文件及内容租约上限不能替代该总额保证。600秒24路混合负载、所有V7场景与真实Host/物理操作也尚未验收。已有资源探针仅证明128MiB/1GiB独立下载和20次取消关闭；不能代替持续混合负载结果。
