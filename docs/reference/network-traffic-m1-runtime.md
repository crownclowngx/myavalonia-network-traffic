# V4 · M1 当前运行行为与边界

更新日期：2026-09-30。实现入口为 [V3 执行计划](../roadmap/network-traffic-v3-m1-capture-plan.md)，V4 UX 的实际验证状态见[实施记录](../archive/2026-09-30-v4-m1-ux-implementation.md)。本文件说明产品行为，不把自动测试当作真实 Host 或真实客户端验收。

2026-10-03 V7补充：生产容器已加入独立[请求调试](network-traffic-m4-request-debugging.md)，使用Manual/Replay来源和独立会话，不替换捕获Current；列表摘要显示来源。代理记录、调试记录与文件资产共用4GiB根额度和32MiB内容额度，其他捕获上限保持。旧schema1仍只有一套请求头/正文，可证明完整时才能提取LegacyObserved；并未增加原始/有效双快照。

## 1. 接入与产品范围

HTTP 工作台使用手动启动的回环显式代理，默认端口 0，由系统分配后显示实际地址。每次运行生成新的内存 CA，面板提供公开 PEM、SHA-256 指纹、有效期及运行代次。插件不设置系统代理、不安装系统根、不导出私钥。客户端需要自行配置代理和本次公开根；证书固定或绕开显式代理的客户端不在兼容承诺内。

依赖继续固定官方 Titanium.Web.Proxy **7.0.13**；2026-09-29 直接核对 GitHub API 的[最新正式发布](https://github.com/justcoding121/titanium-web-proxy/releases/tag/v7.0.13)及 NuGet 索引，两者均为此版本，发布提交为 `571b7ac896df5986fd3a31f7e02d73fe4bd501a5`。未引入维护分支、源码补丁或私有反射接口。

**本次用户确认的产品降级：HTTP/2 空闲流仅提示，不自动终止。** 固定发布包的公开 `TerminateSession()` 取消源属于连接，无法安全替代单流取消。达到空闲阈值后，概览显示限制，该流继续为 Receiving / Partial；其他流继续运行。用户可在客户端取消目标流，或停止整个代理。需要代理主动空闲超时的请求使用 HTTP/1.1。接入面板在启动前后均显示此范围；P06 验证同连接隔离、取消后继续接收和全局停止，不宣称自动取消已实现。

普通 HTTP/1.1、HTTPS 与无目标映射的 HTTP/2 保留支持；受控目标映射仍只协商 HTTP/1.1，未提供产品规则编辑页。HTTP/3、WebSocket/gRPC 专用解析、DSL、主动发送/重发、HAR 导入及视频播放留到后续里程碑。

## 2. 列表、详情与状态

Document 顶部保留状态、实际代理地址、启停、保存快照、打开菜单与设置。设置覆盖右侧，不改变内容高度；独立 Tool 保留常驻启停。列表使用 48 DIP 双行摘要：方法、可读路径、HTTP 状态和耗时在首行，域名、不完整状态及双向合计的“已存”大小在次行；完整时间与原路径可查看提示。重复 URL 不合并；Source 当前均为 Captured。未知状态码/长度保留未知。路径列可截断，筛选使用保留的完整有效 URI，不用截断显示列做搜索。

“更多筛选”提供方法集合、关键字、状态类/精确状态码、传输状态和开始时间区间；不同条件 AND，方法集合 OR，时间为 `[开始,结束)`。输入消抖 200 ms，每页 100 ms 拉取，单次最多更新 200 行。虚拟列表只创建视口附近的行容器。输入草稿、组合文字及非法条件保留上次有效结果；生效标签只反映已应用查询。状态类和精确状态码互相替代，方法下拉与方法集合为同一来源。清除筛选保留清空游标；“仅看清空后”标签可单独移除恢复范围。清空本页只改变页面游标，活动记录仍保留；其他页面和底层捕获不变。

详情默认正文，五个标签为正文、概览、参数、Headers、Cookie。方向选择同时控制正文、Headers 和导出；参数固定为请求 Query，Cookie 标注两侧。JSON 默认格式化，树形/原文互斥；查找只检索当前有限文本，最多 256 字符，提供下一处和换行控制。导出是工具栏动作。Query 保留重复项、空值、原始编码及非法转义诊断；URI 的 `+` 不变为空格。Header 以多值序列保存，Set-Cookie 不按 Expires 中的逗号拆分。认证值默认遮罩，勾选“显示原值”仅改变本页展示；存档和正文导出仍包含实际记录内容。

| 维度 | 含义 |
| --- | --- |
| Receiving / Completed / Cancelled / Failed | 网络传输事实；成功 HTTP 状态不等于正文已完整 |
| MetadataOnly / Partial / Complete / Failed | 该方向的记录事实；Complete 要求正常结束、连续前缀覆盖全部观察字节、已知长度一致且写入已提交 |
| 预览截断/解析失败 | 仅影响当前查看能力，不修改原始正文或网络结果 |
| 只读存档 | 显示快照当时状态；“保存时接收中”不代表重开后恢复网络任务 |

## 3. 内容与记录预算

请求和响应均从公开增量回调观察，保存的是去掉 HTTP framing 后的编码实体字节，gzip/br 保留编码状态；显示时有限解压，不重复解码，也不改写保存体。

未知长度 h1 chunked 上传还核对客户端真实结束块。客户端提前断开时，固定代理库可能向上游补写结束块，所以“上游有响应/回执”不能证明原请求完整；未观察到真实末块时请求方向标记 Partial 和 IncompleteFraming。取消不能撤销上游已收到的字节，工作台不会自动重放请求。

| 项目 | 当前边界 |
| --- | --- |
| 活动请求与摘要 | 最多 20 活动；保留最多 10,000 已结束摘要；摘要 16 MiB，达到任一上限淘汰最旧已结束记录 |
| 元信息 | URI 8,192 字符；每方向 Header 64 KiB/256 项；结束记录头缓存 128 条/16 MiB；每会话日志 64 MiB、队列 128 条/4 MiB |
| 仅元信息 | 不保存正文；仍可对支持的未压缩流进行有界实时观察 |
| 有限内容（默认） | 请求、响应各最多 1 MiB |
| 受配额落盘 | 请求、响应各最多 1 GiB；整个会话默认 1 GiB，包含元信息，所以单个 1 GiB Body 可能只保存前缀 |
| 磁盘总量 | 会话可通过 API 显式配置至 2 GiB；托管根目录合计 4 GiB；启动扫描本插件标记的旧会话，残留继续计费 |
| 正文队列 | 请求/响应共用 4 MiB、256 块；在写块也计费；第一次丢块后停止该方向记录，保留连续前缀 |
| 预览与 JSON | 普通文本输出最多 64 KiB UTF-8；JSON 输入/格式化输出最多 1 MiB，深度 64、节点 10,000；解压超过 64 KiB 后限制膨胀比 100:1 |
| SSE / NDJSON | 每流最近 256 事件且共 256 KiB；单事件/行 64 KiB；独立观察队列 128 块/1 MiB，单块 64 KiB；20 活动、2 个已完成观察器 |
| 共享内容预算 | 所有页面、事件观察和图片共用 32 MiB 预留，额度不足时降级预览 |
| PNG / JPEG | 完整编码输入最多 4 MiB、4,000,000 像素、每边 8,192；缩略最长边 512；解码并发 1、最多 2 个等待者 |
| 时间 | 连接 5 秒、响应头 10 秒；响应空闲默认 30 秒（h1 自动取消、h2 仅提示）；活跃流无短总超时；停止/退出截止 10 秒 |

URI 8,192 字符限制继承 M0 路由验证：超过范围会拒绝该请求；Header 记录超限只影响记录元信息。两者不能混为同一种截断行为。

SSE 支持 UTF-8/BOM、CR/LF/CRLF、data/event/id/retry、注释心跳；不主动重连，EOF 半事件不派发。NDJSON 坏行保留诊断且不吞后续合法行，异常 EOF 尾行不视为完成。列表和事件分别拥有跟随开关；离开最新位置、选择旧请求或流内文字时暂停相应阅读区域。新增提示只计当前保留且匹配的水位后记录；修订不重复计数，换筛选重建计数水位。回到最新不改选中请求。事件跟随入口固定在正文视口外，滚到历史也能恢复。接收、记录与解析继续。

实时事件观察首版支持**未压缩** SSE/NDJSON。压缩流按已记录有限前缀尝试解压/解析，未收全压缩数据时可能无法预览，不承诺压缩流首事件实时出现。事件环淘汰、观察丢块与正文记录截断分别提示；正文到顶不阻止独立观察继续。已完成观察器淘汰后，只能从保存的前缀重建，不能恢复未保存尾部。

图片超过尺寸、输入不完整或解码失败时只展示诊断；文件/视频提供元信息、字节进度、有限十六进制与已有正文导出。206 表示本次 HTTP 响应片段，不拼接整个资源，不自动播放或补下载。

## 4. 保存、重开与恢复

原生目录含 `manifest.json`、`records.jsonl` 与 `bodies/<recordId>.<direction>.bin`。保存使用新目录名，不覆盖已有目标；同父目录临时写入、校验 SHA-256、flush 后原子改名。保存弹层说明会话范围，可浏览父目录并编辑最终新目录，或直接输入完整路径；最终确认保存时冻结记录状态和已提交长度，后到字节不混入快照；长流无需等结束。每个容器最多一个保存操作。保存包含当前源会话仍保留的全部记录，包括被筛选隐藏项。选择器取消不启动保存，换源或切导出方向使旧操作失效；平台选择器不可用时显示原因并保留路径输入。

存档和导出目标必须在托管捕获根目录**之外**，避免复制正文绕过捕获根配额。单存档正文最多 2 GiB、索引 64 MiB、manifest 4 MiB、10,020 条记录。外部目标由用户管理；磁盘不足时失败，不覆盖旧目标。保存任务失败只清理自己生成的临时目录。

重开校验版本、路径、实际长度、摘要和状态一致性；拒绝绝对/越界/重解析路径、重复身份和未来版本。索引损坏拒绝打开；个别 Body 缺失/变更可降级为 Failed，并显示原因。当前只读加载以 32 MiB 元信息估算作为硬边界，超限明确拒绝；尚未实现任意大索引分页浏览。

“恢复工作目录”仅处理显式选择的、带本插件会话标记的目录，读取完整日志行，忽略破损末行并显示恢复诊断。只恢复实际持久化的元信息和已提交文件；它不是断点续传，不补发请求。事件环本身不存档，历史只解析正文中仍可证明的范围。

默认捕获根为 `%LOCALAPPDATA%\NetWorkTrafficPlugin\Captures`。运行持有 `.capture.lock`，防止同根并行写入。旧会话不会自动删除；摘要淘汰也不立即删除正文。当前没有产品化历史会话管理页，释放磁盘需先停止并关闭读取该目录的页面，再管理确认属于本插件的旧会话目录；不要删除未知或外部目录。

## 5. 生命周期与验证边界

一个容器共享一个协调器、当前捕获源和内容预算。Document 的筛选、选择、方向、正文模式、分栏、两个跟随和只读模式互不干扰；关闭最后一个页面仍继续代理。页面关闭会取消读取、解除刷新、归还位图与内容租约；旧请求迟到不能覆盖新的选择。宽屏可拖分栏，窄屏保留返回和上下条；Ctrl+L 聚焦请求搜索、Ctrl+F 查找文本，Esc 每次关闭一层。成功反馈 3 秒消失，悬停/焦点停留暂停计时，错误保留至关闭。插件退出同时收口代理和存档任务，失败时保留 Faulted，不能假称已经释放。

测试分别覆盖纯模型、真实回环协议、文件故障、生产 Headless View 和 Avalonia Desktop 十分钟测量。Desktop 探针位于屏幕外、不激活窗口，测量 Dispatcher 操作和布局；不是物理输入延迟或真实 Host 验收。真实客户端、Host 多页/Dock/Tool 与人工混合流程仍按 H 项单独登记。
